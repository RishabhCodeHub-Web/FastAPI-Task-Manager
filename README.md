# FastAPI Task Management Web App

A robust and scalable Full-Stack Task Management application built using Python (FastAPI) for the backend and connected with a database.

## Features
- **User Authentication:** Secure signup and login functionality.
- **CRUD Operations:** Create, Read, Update, and Delete tasks smoothly.
- **Automation:** Integrated background tasks to send automated reminders for upcoming deadlines.

## Tech Stack
- **Backend:** Python, FastAPI, Uvicorn
- **Database:** SQLite / MySQL
- **Tools:** Git, GitHub
